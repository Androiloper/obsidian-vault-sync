Obsidian Vault Sync

A personal tool that keeps my own Obsidian notes in step between my computer and my phone.

What it is

Obsidian Vault Sync is a plugin for the note-taking app Obsidian. It copies the notes in a vault to a folder in the owner's Google Drive, and copies changes back, so the same notes are available on each of the owner's devices.

It is built and used by one person, for that person's own notes. It is not a product or a service, and it is not offered to the public.

How it uses Google Drive

The plugin asks for the narrowest Drive permission Google offers: access only to the files and folders it created itself. It cannot see or change anything else in the Drive.
